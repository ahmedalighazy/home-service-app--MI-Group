# Help Center Screen

**الملف:** `presentation/screens/help_center_screen.dart`
**الـ Route:** `AppRouter.helpCenter`
**الـ Class:** `HelpCenterScreen`

---

## الوصف

شاشة مركز المساعدة. بتجمع الأسئلة الشائعة والدعم الفني (Tickets) في مكان واحد.

---

## محتوى الشاشة

```
┌────────────────────────────────────────┐
│  AppBar: "مركز المساعدة"               │
├────────────────────────────────────────┤
│                                        │
│  ┌─────────────────────────────────┐   │
│  │  📖  الأسئلة الشائعة        ›   │   │
│  └─────────────────────────────────┘   │
│                                        │
│  الدعم الفني          [+ مشكلة جديدة] │
│                                        │
│  ┌─────────────────────────────────┐   │
│  │  [Ticket 1 — مفتوح]         ›   │   │
│  └─────────────────────────────────┘   │
│  ┌─────────────────────────────────┐   │
│  │  [Ticket 2 — تم الحل]       ›   │   │
│  └─────────────────────────────────┘   │
└────────────────────────────────────────┘
```

---

## الـ Widgets المستخدمة

| Widget                   | الوصف                                        |
| ------------------------ | -------------------------------------------- |
| `HelpCenterItem`         | بطاقة "الأسئلة الشائعة" — بتروح لـ FAQScreen |
| `TechnicalSupportHeader` | هيدر قسم الدعم الفني + زر "مشكلة جديدة"      |
| `TicketCard`             | كارد يعرض تذكرة دعم واحدة                    |

---

## `TechnicalSupportHeader` — التفاصيل

- بيعرض عنوان "الدعم الفني" على اليسار.
- زر "مشكلة جديدة" على اليمين — بيفتح `NewIssueBottomSheet` بـ `showModalBottomSheet`.

---

## `TicketCard` — التفاصيل

**Props:**

| Prop          | النوع           | الوصف                           |
| ------------- | --------------- | ------------------------------- |
| `title`       | `String`        | عنوان التذكرة                   |
| `status`      | `String`        | الحالة (مثل "مفتوح"، "تم الحل") |
| `statusColor` | `Color`         | لون badge الحالة                |
| `ticketCode`  | `String`        | رقم التذكرة مثل `TKT.1001`      |
| `time`        | `String`        | وقت فتح التذكرة                 |
| `description` | `String`        | ملخص المشكلة                    |
| `onTap`       | `VoidCallback?` | بيروح لـ `ChatDetailScreen`     |

**شكل الكارد:**

```
┌──────────────────────────────────────┐
│  عنوان التذكرة    [مفتوح]         ›  │
│  TKT.1001         منذ يوم            │
│                                      │
│  💬  ملخص المشكلة ...               │
└──────────────────────────────────────┘
```

---

## `NewIssueBottomSheet` — شكل الـ Bottom Sheet

Bottom sheet بيظهر من أسفل الشاشة لإنشاء تذكرة جديدة.

**المحتوى:**

- عنوان المشكلة (text field)
- رقم الطلب المرتبط (text field)
- وصف المشكلة (text area — 4 أسطر)
- زر "إرسال" — حالياً بيعمل `context.pop()` بس

> ⚠️ **غير مكتمل:** زر الإرسال مش بيبعت أي data.

---

## بيانات الـ Tickets

الـ Tickets حالياً هاردكود مباشرة في الشاشة:

|         | Ticket 1                  | Ticket 2                  |
| ------- | ------------------------- | ------------------------- |
| العنوان | `AppStrings.ticketTitle1` | `AppStrings.ticketTitle2` |
| الحالة  | "مفتوح" — أخضر            | "تم الحل" — رمادي         |
| الكود   | `TKT.1001`                | `TKT.1002`                |

> ⚠️ **غير مكتمل:** مفيش API — البيانات ثابتة في الكود.
